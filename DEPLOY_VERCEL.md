# Деплой на Vercel с кастомным доменом GoDaddy

## Почему Vercel?

✅ **Бесплатный** - отличный бесплатный план для статических сайтов  
✅ **Быстрый** - глобальная CDN, сайт загружается мгновенно  
✅ **Простой** - деплой в 2 клика  
✅ **SSL автоматически** - бесплатный HTTPS сертификат  
✅ **Отличная поддержка доменов** - легко подключить домен с GoDaddy

## Шаг 3: Деплой проекта

### Вариант A: Деплой через GitHub (рекомендуется)

1. **Убедитесь, что ваш код на GitHub:**
   ```bash
   # Если еще не загрузили на GitHub:
   git add .
   git commit -m "Prepare for Vercel deployment"
   git push origin main
   ```

2. **В Vercel:**
   - Нажмите **"Add New..."** → **"Project"**
   - Выберите ваш репозиторий `ega`
   - Vercel автоматически определит настройки (Vite + React)
   - Нажмите **"Deploy"**

3. **Готово!** Через 1-2 минуты сайт будет доступен по адресу `https://ega-xxx.vercel.app`

### Вариант B: Деплой через Vercel CLI

1. **Установите Vercel CLI:**
   ```bash
   npm i -g vercel
   # или
   yarn global add vercel
   ```

2. **Войдите в Vercel:**
   ```bash
   vercel login
   ```

3. **Деплой:**
   ```bash
   cd /Users/yury/Documents/Ega
   vercel
   ```

4. **Следуйте инструкциям:**
   - Выберите проект (или создайте новый)
   - Подтвердите настройки
   - Дождитесь завершения деплоя

## Шаг 4: Подключение домена GoDaddy

### 4.1. Добавление домена в Vercel

1. **В Vercel Dashboard:**
   - Откройте ваш проект
   - Перейдите в **Settings** → **Domains**
   - Введите ваш домен (например: `example.com` или `www.example.com`)
   - Нажмите **"Add"**

2. **Vercel покажет DNS записи**, которые нужно добавить в GoDaddy

### 4.2. Настройка DNS в GoDaddy

1. **Войдите в аккаунт GoDaddy:**
   - Перейдите на [godaddy.com](https://godaddy.com)
   - Войдите в аккаунт

2. **Откройте DNS настройки:**
   - Перейдите в **My Products** → найдите ваш домен
   - Нажмите **"DNS"** или **"Manage DNS"**

3. **Добавьте DNS записи:**

   **Для домена без www (example.com):**
   - Найдите или создайте запись типа **A**
   - **Name/Host:** `@` или оставьте пустым
   - **Value/Points to:** IP адрес от Vercel (обычно `76.76.21.21`)
   - **TTL:** `600` (или оставьте по умолчанию)
   - Сохраните

   **Для домена с www (www.example.com):**
   - Создайте запись типа **CNAME**
   - **Name/Host:** `www`
   - **Value/Points to:** `cname.vercel-dns.com`
   - **TTL:** `600`
   - Сохраните

   **Альтернатива (рекомендуется Vercel):**
   - Используйте **CNAME** записи для обоих вариантов:
     - `@` → `cname.vercel-dns.com` (если GoDaddy поддерживает CNAME для корня)
     - `www` → `cname.vercel-dns.com`

4. **Проверьте записи:**
   - Убедитесь, что старые A/CNAME записи удалены или изменены
   - Сохраните все изменения

### 4.3. Ожидание распространения DNS

- DNS изменения могут занять от **5 минут до 48 часов**
- Обычно это занимает **15-30 минут**
- Проверить можно командой: `nslookup example.com` (замените на ваш домен)

### 4.4. Проверка в Vercel

1. **В Vercel Dashboard:**
   - Перейдите в **Settings** → **Domains**
   - Дождитесь статуса **"Valid Configuration"** (зеленая галочка)
   - Vercel автоматически выдаст SSL сертификат

2. **Проверьте сайт:**
   - Откройте ваш домен в браузере
   - Должен открыться ваш сайт с HTTPS

## Шаг 5: Автоматический деплой

После подключения GitHub репозитория, каждый push в `main` автоматически деплоит сайт!

```bash
git add .
git commit -m "Обновление сайта"
git push
```

Vercel автоматически:
- Соберет проект
- Задеплоит новую версию
- Обновит сайт на вашем домене

## Решение проблем

### DNS не обновляется
- Подождите до 48 часов (обычно 15-30 минут)
- Проверьте правильность записей в GoDaddy
- Убедитесь, что удалили старые записи

### SSL сертификат не выдается
- Дождитесь полного распространения DNS
- Проверьте, что домен правильно настроен в Vercel
- Подождите 5-10 минут после настройки DNS

### Сайт не открывается
- Проверьте DNS записи через `nslookup`
- Убедитесь, что домен добавлен в Vercel
- Проверьте логи деплоя в Vercel Dashboard
